# $ASHCAT

Мем-коин лендинг: офисный кот-профессионал вскакивает из-за стола, увидев зелёную свечу, и бежит в полный рост по радужному мосту.

Чистый HTML/CSS/JS, без сборки.

## Деплой
Просто залить содержимое папки как статический сайт (GitHub Pages / Vercel / Netlify — без build command, preset "Other"/"Static").

## Что доделать при запуске токена
В `script.js` в объекте `CONFIG` вписать:
- `CA` — адрес контракта (включит копирование и реальные данные с DexScreener)
- `CHART_URL` — ссылка на дексскринер/чарт
- `BUY_URL` — ссылка на покупку (pump.fun/dex)

Также заменить контракт-заглушки в `index.html` (`#caValue`, `#caValueFooter`) и добавить реальные ссылки на Telegram/Dexscreener в футере.
